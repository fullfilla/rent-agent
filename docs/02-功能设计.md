# 02-功能设计

## 用户角色

- 租客用户：输入需求、浏览房源、收藏候选、查看风险提示。
- Agent：理解用户自然语言、更新筛选条件、解释推荐理由、提示租房风险。
- 数据源适配器：提供房源数据。MVP 为 mock 数据，后续可替换为平台 API、企业数据服务或用户导入文件。

## 用户完整流程

1. 用户打开本地应用，看到类 Codex 的三栏工作台：左侧需求与配置，中间对话，右侧房源结果。
2. 用户在对话框输入需求，例如“我在望京上班，预算 6500，希望一居室，离地铁近，不要隔断”。
3. Agent 解析需求，更新筛选器，并输出执行过程：理解需求、刷新房源、匹配排序、风险检查。
4. 系统展示匹配房源列表，用户查看匹配分、价格、位置、通勤、风险标签和推荐理由。
5. 用户继续对话，例如“预算降到 6000，优先整租，可以远一点但地铁 800 米内”。
6. Agent 再次更新筛选和排序。
7. 用户也可以直接在筛选器中调整城市、区域、租金、户型、整租/合租、地铁距离、电梯、宠物等条件。
8. 用户点击刷新，系统模拟拉取新房源并更新时间；也可开启自动刷新。
9. 用户在设置区填写第三方模型配置，保存到本地。

## 功能模块清单

- 对话式租房需求收集。
- 类贝壳筛选条件。
- 房源列表与房源详情摘要。
- 匹配分和排序。
- 租房风险识别与提示。
- Agent 执行过程展示。
- 房源刷新：手动刷新和自动刷新模拟。
- 第三方模型配置。
- 收藏、复制推荐摘要、导出 JSON。

## 核心功能 / 重要功能 / 暂不实现功能

### 核心功能

- 对话推荐房源。
- 根据后续对话调整需求。
- 手动筛选房源。
- 风险提示和风险筛选。
- 模型配置保存。
- 手动刷新与自动刷新模拟。

### 重要功能

- 收藏候选房源。
- 复制推荐摘要。
- 导出当前结果 JSON。
- 移动端响应式布局。

### 暂不实现功能

- 真实贝壳、安居客账号登录。
- 真实平台 API 调用。
- 自动爬取网页房源。
- 地图找房。
- 在线支付、预约看房、合同签署。
- 多用户账号系统和云端同步。

## 每个核心功能的输入、处理、输出

### 对话推荐房源

- 输入：用户自然语言需求、当前筛选条件、mock 房源数据。
- 处理：解析预算、城市/区域、户型、租住方式、地铁距离、风险偏好；计算匹配分；生成推荐理由。
- 输出：Agent 回复、更新后的筛选条件、排序后的房源列表、执行步骤。

### 后续对话调整需求

- 输入：新一轮用户消息和历史筛选条件。
- 处理：合并增量偏好，例如“预算降到 6000”“不要合租”“可接受远一点”。
- 输出：更新后的筛选条件和新推荐。

### 手动筛选房源

- 输入：表单控件中的城市、区域、价格、户型、整租/合租、地铁距离、电梯、宠物、风险过滤。
- 处理：过滤 mock 房源，重新计算匹配分。
- 输出：符合条件的房源卡片。

### 风险提示

- 输入：房源字段和描述文本。
- 处理：规则检测低价异常、转租、隔断、押金高、服务费、无独卫、楼层不便、距离地铁远等。
- 输出：风险标签、解释、建议追问问题。

### 模型配置

- 输入：API Key、Base URL、模型名称。
- 处理：保存到 localStorage；MVP 不实际发送请求。
- 输出：配置保存成功提示和当前配置摘要。

### 房源刷新

- 输入：手动点击或自动刷新开关。
- 处理：更新时间，模拟新增房源或调整房源新鲜度。
- 输出：刷新日志、新房源标记、最新刷新时间。

## 页面结构

- 顶部栏：产品名称、刷新状态、导出按钮。
- 左侧栏：筛选器、自动刷新、模型配置、收藏列表。
- 中间区：对话消息、Agent 执行过程、输入框。
- 右侧区：房源列表、排序、风险提示、复制摘要。

## 数据字段草案

### RentalListing

- id：房源 ID。
- title：标题。
- source：来源，例如 mock-beike、mock-anjuke、user-api。
- city：城市。
- district：区域。
- community：小区。
- address：地址摘要。
- rent：月租金。
- depositMonths：押金月数。
- payMonths：付款周期月数。
- rooms：户型。
- rentalType：整租或合租。
- area：面积平方米。
- floor：楼层描述。
- hasElevator：是否电梯。
- subwayDistance：距地铁米数。
- commuteMinutes：通勤分钟数。
- orientation：朝向。
- tags：普通标签。
- riskFlags：风险标签。
- description：描述。
- updatedAt：更新时间。
- isNew：是否新房源。

### SearchCriteria

- city、districts、budgetMin、budgetMax、rooms、rentalType、maxSubwayDistance、maxCommuteMinutes、mustHaveElevator、allowPets、excludeHighRisk、keywords。

### ModelConfig

- providerName、baseUrl、apiKey、modelName。
