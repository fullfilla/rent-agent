# 05-测试验收

## 验收标准

- 本地可启动，打开后显示完整租房 Agent 工作台。
- 顶部必须有明确产品标题和当前页面名称。
- 左侧为 Codex 式导航，上方放 Agent 对话、房源聚合、地图找房，左下角放设置。
- Agent 对话记录在左侧下方归档。
- 新对话会创建独立会话，不会清空历史会话；旧会话保留在归档中。
- 已加入三层记忆：短期记忆为当前会话近期需求，中期记忆为历史会话摘要，长期记忆为用户画像。
- 房源聚合页内包含筛选条件，筛选条件接近贝壳租房常用筛选：位置、租金、户型、方式、面积、朝向、楼层、付款方式、地铁距离、通勤、特色、电梯、宠物、风险过滤。
- 地图找房页使用同一套筛选条件，并在地图区域展示匹配房源点位。
- 右侧输出栏已移除，内容空间主要留给当前页面。
- 桌面、平板、手机宽度下布局可用，不依赖三栏挤压。
- 可通过对话输入租房需求并看到 Agent 回复。
- 可收藏房源、复制摘要、导出 JSON。
- 可保存模型配置到本机浏览器。
- 前台设置页仅保留大模型 API 配置。
- 贝壳、安居客、58 同城 API 改为服务端环境变量配置，不暴露到浏览器。
- 生产服务提供 `/api/health` 和 `/api/listings` 接口。
- 可手动刷新并看到房源更新。
- 可开启自动刷新模拟。

## 已知问题

- 当前房源数据为 mock 数据，不代表真实平台库存。
- 地图为 mock 地图，不是高德、百度或 Mapbox SDK。
- 模型配置目前只保存，不执行真实请求。
- 自动刷新依赖浏览器页面保持打开。
- 风险规则为启发式规则，不能替代人工核验合同。
