# 06-部署上线

## 上线形态

本项目已调整为可上线结构：

- 前台：React + Vite 构建出的静态页面。
- 后台：Node.js 服务，托管静态页面并提供 `/api/listings` 房源聚合代理接口。
- 用户前台只填写大模型 API。
- 贝壳、安居客、58 同城 API Key 只放在服务端环境变量中，避免暴露到浏览器。

## 本地生产模式验证

在项目目录运行：

```powershell
cd E:\codex空间\rent-agent-mvp
npm install
npm run build
npm start
```

访问：

```text
http://127.0.0.1:3000
```

健康检查：

```text
http://127.0.0.1:3000/api/health
```

房源代理接口：

```text
http://127.0.0.1:3000/api/listings?provider=all
```

## 服务端环境变量

复制 `.env.example` 中的变量到你的服务器环境变量配置中。

```env
PORT=3000

BEIKE_API_BASE_URL=
BEIKE_API_ENDPOINT=/rent/listings
BEIKE_API_KEY=

ANJUKE_API_BASE_URL=
ANJUKE_API_ENDPOINT=/rent/listings
ANJUKE_API_KEY=

WUBA_API_BASE_URL=
WUBA_API_ENDPOINT=/rent/listings
WUBA_API_KEY=
```

说明：

- `BASE_URL` 是平台或你自己的代理服务主地址。
- `ENDPOINT` 是房源列表接口路径。
- `API_KEY` 是服务端调用平台接口的密钥。
- 如果某个平台没有配置，后台会标记为未配置，并继续返回 mock fallback。

## 阿里云 ECS 部署步骤

1. 购买 ECS 或轻量应用服务器，系统建议 Ubuntu 22.04。
2. 安装 Node.js 20 LTS。
3. 上传项目到服务器，例如 `/var/www/rent-agent-mvp`。
4. 在项目目录安装依赖并构建：

```bash
cd /var/www/rent-agent-mvp
npm install
npm run build
```

5. 配置环境变量。可以先临时运行：

```bash
export PORT=3000
export BEIKE_API_BASE_URL="你的贝壳接口地址"
export BEIKE_API_KEY="你的贝壳授权 key"
export ANJUKE_API_BASE_URL="你的安居客接口地址"
export ANJUKE_API_KEY="你的安居客授权 key"
export WUBA_API_BASE_URL="你的58接口地址"
export WUBA_API_KEY="你的58授权 key"
npm start
```

6. 用浏览器访问：

```text
http://服务器公网IP:3000
```

7. 在阿里云安全组放行 `3000` 端口，或用 Nginx 反向代理到 80/443。

## 推荐生产运行方式

建议使用 PM2 守护进程：

```bash
npm install -g pm2
cd /var/www/rent-agent-mvp
pm2 start server/index.js --name rent-agent
pm2 save
pm2 startup
```

查看状态：

```bash
pm2 status
pm2 logs rent-agent
```

重启：

```bash
pm2 restart rent-agent
```

## Nginx 反向代理示例

```nginx
server {
    listen 80;
    server_name your-domain.com;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

配置 HTTPS 时，可以在阿里云或服务器上使用 Certbot 申请证书。
